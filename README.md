# Temer Properties — Smart Real Estate Platform

## Included
- AI-style natural-language property search
- Property recommendations/search filtering
- Interactive map page using Leaflet
- Saved properties
- Customer dashboard
- Property alerts
- Viewing/lead-ready property details
- Mortgage/affordability calculator
- Admin property editor
- English / Amharic-ready language toggle
- Responsive mobile-first design
- Railway-ready Flask deployment

## Run locally
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Railway
Connect this folder/repository to Railway. The included Procfile runs Gunicorn.
